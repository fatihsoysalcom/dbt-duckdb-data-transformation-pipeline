# dbt DuckDB Data Transformation Pipeline

This example demonstrates a simplified data engineering pipeline using DuckDB in Python, mimicking dbt's layered transformation approach. It processes raw CSV data through staging and aggregation steps to produce a clean, aggregated data product, illustrating how raw data can be transformed into meaningful insights.

## Language

`python`

## How to Run

1. Ensure Python and `duckdb` are installed (`pip install duckdb`).
2. Save the code as `main.py`.
3. Run from your terminal: `python main.py`
